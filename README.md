
# BankingQAAutomation

## Project Overview
A Selenium-based web UI automation framework using Java and TestNG.

## Features
- Page Object Model (POM)
- Data-driven testing using CSV and Excel
- TestNG test execution
- Extent HTML reporting
- Failure screenshot capture
- Log4j2 loggssing
- Maven build management

## Tools and Technologies
- Java
- Selenium WebDriver
- TestNG
- Maven
- Apache POI
- ExtentReports
- Log4j2
- Git and GitHub

Learning feature branches and safe code changes.
